# ⏱ TimeFlow Pro

Tracker de temps expert — PWA installable sur mobile.

## Déploiement GitHub Pages

1. Crée un repo GitHub nommé `timeflow` (ou `timeflow-pro`)
2. Upload les 6 fichiers de ce dossier
3. Settings → Pages → main → / (root) → Save
4. URL : `https://mbongbenoit-jpg.github.io/timeflow/`
5. Chrome Android : menu ⋮ → "Ajouter à l'écran d'accueil"

## Fichiers
- `index.html` — Application complète
- `manifest.json` — Config PWA
- `sw.js` — Service Worker
- `icon-192.png` / `icon-512.png` — Icônes
