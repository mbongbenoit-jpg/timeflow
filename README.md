# ⏱ TimeFlow

Tracker de temps hebdomadaire — PWA installable sur mobile.

## Déploiement GitHub Pages

1. Crée un repo GitHub nommé `timeflow`
2. Upload tous les fichiers de ce dossier
3. Va dans **Settings → Pages → Source → main → / (root)** → Save
4. Ton app sera disponible sur : `https://mbongbenoit-jpg.github.io/timeflow/`
5. Sur Android Chrome : menu ⋮ → "Ajouter à l'écran d'accueil"

## Fichiers
- `index.html` — Application complète
- `manifest.json` — Config PWA
- `sw.js` — Service Worker (offline + notifications)
- `icon-192.png` — Icône app
- `icon-512.png` — Icône splash screen
